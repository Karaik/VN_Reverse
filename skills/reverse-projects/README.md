# reverse-projects

## 作用

这个分类存放“title 级逆向项目”的流程型技能。

它解决的问题不是单个函数怎么分析，而是：

- 逆向 title 的正式目录和入口怎么收口
- 主 README 怎么承担用户主入口职责
- 结构 / 用法 / 验证文档怎么分工
- 反编译 / 回编 / 编码写回 / 总验证怎么进入正式链

## 当前技能

- `reverse-title-readme`
  - 用于统一逆向 title 主 README 的写法和命令边界。

## 适用场景

- 新建一个逆向 title 的正式 README
- 把旧逆向 title 的主 README 收成正式主入口
- 检查 README 是否把命令写全、编码写全、验证写全

## 不负责的事情

这个分类不负责：

- 单个函数符号恢复
- 单个结构体重建
- 只针对某个局部逆向问题的分析任务

这类事情应放到 `reverse-engineering/`。
