# マスカレード 主线清单

最后更新：`2026-03-18`

## 当前目标

把 `マスカレード` 收紧为“静态文本写回前置逆向”工程。

主线只保留：

- 文本载体
- 文本定位
- 偏移敏感字段白名单
- 变长文本静态重定位前提
- 与这些目标直接相关的验证

历史研究进度与细节已从主线清单移出，不再作为默认入口。
