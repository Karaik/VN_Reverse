# SSB 结构

## 当前已确认

- 脚本主载体位于 `game/SCRIPT/`。
- `CODE.SSB` 是 32 位词流。
- `DATA.SSB` 是脚本数据载体。
- `DATA.SSB` 在当前链路中使用 `XOR 0xAA` 处理。
- `CODE.SSB` 中负值词是操作码，非负值词既可能是立即数，也可能是 `DATA.SSB` 的 4 字节对齐偏移。
- 当前已确认可以从 `DATA.SSB` 中扫描出可读字符串，并结合 `CODE.SSB` 引用关系建立正式文本表。
- 当前已确认存在两条已落地的文本识别路径：
  - 文本相关窗口引用
  - 主显示链引用
- `translation_entries.json` 当前是“可正式导出并回写的字符串子集”，不是全部字符串总表。

## 当前正式文本模型

- `strings`
  - 全量可读字符串扫描结果
  - 保留字节偏移、词偏移、原始字节、引用计数
- `text_entries`
  - 从 `strings` 中筛出的正式文本候选
- `translation_entries`
  - 当前正式文本修改入口
  - 当前包含所有被脚本正式引用的 `jp_text` / `text` 条目

## 当前 usage 字段边界

- `main_display_text`
  - 已命中主显示链的条目
- `table_entry`
  - 已命中特定表项调用模式的条目
- `text`
  - 已进入正式文本表，但还未进一步精细分型的条目

当前没有把“说话人 / 正文 / 选项 / 标签”完整拆成稳定正式模型。

## 当前未确认

- `CODE.SSB` 全部 opcode 的完整语义。
- `DATA.SSB` 中文本块、控制流数据、其他结构数据的精确边界。
- 说话人、正文、选项、标签的完整结构化配对模型。
