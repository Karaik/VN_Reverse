```powershell
python .\regression_test.py
```

- `CODE.SSB` unchanged roundtrip
- `DATA.SSB` unchanged roundtrip
- 所有正式引用文本零漏提进入 `translation_entries`
- 姓名样本可写回并再次反编译恢复

- 反编译与回编基础链路可跑通
- 正式文本表不是空壳，所有被脚本正式引用的 `jp_text` / `text` 条目都已进表
- 文本修改后能回编
